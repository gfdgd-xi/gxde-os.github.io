# GXDE 25.5beta1 更新日志（2026.08.26）

![GXDE 25.5beta1 X11](/news/25.5b1/desktop-x11.jpg)  

GXDE 25.5 是 GXDE 有史以来单次更新最多的版本，包括 Wayland 的全面支持、Qt6 迁移、内核更新、驱动升级、安全漏洞修复、故障修复等。本次更新涉及超过 60 个代码仓库，新增功能、修复补丁、性能优化、安全加固累计数百项。



## Wayland 支持基本就绪

GXDE 桌面环境已可完整运行于 Wayland 会话，主要组件均已原生适配：

- 合成器 `gxde-wlcom` 大幅升级，支持会话锁屏、截屏管理、全局快捷键、窗口模糊/圆角等
- 任务栏、顶栏、启动器、控制中心、文件管理器等核心组件均已支持 Wayland
- 托盘图标、截屏录屏、热区、投屏等功能在 Wayland 下可正常使用
- 快捷键与输入法问题基本修复
- 登录管理器 `GXDM` 升级，支持 Wayland/X11 会话切换及全新 UI

> 用户可在登录界面选择 **GXDE Wlcom** 会话体验。

## 更多组件迁移至 Qt6

超过 20 个核心组件完成 Qt6 迁移，包括：任务栏、顶栏、启动器、控制中心、文件管理器、会话管理、文本编辑器、视频播放器、录音机、字体管理器、系统助手、打印机、剪切板等。同时新增多个 Qt6 版本基础库（DFrameworkDBus、gxde-network-utils、disomaster、libdbusmenu、qt6mpris 等）。



## 内核与驱动更新

- 内核更新至 **6.18.44** / **6.6.148**
- 引入 7.2 内核 MGLRU 性能优化，提升 zram 压缩性能与 EXT4/XFS IOPS
- 修复多个内核安全漏洞Januscape（CVE-2026-53359）、SCTPhantom（CVE-2026-64564）、OVSwrap（CVE-2026-64531）等
- 新增 **NVIDIA 470 Tesla / 580 / 595** 系列驱动支持
- 默认使用 NTFS Plus，提升 NTFS 文件系统性能
- 支持在盘古 M900 上启用开源 Panfrost GPU 驱动
- 新增麒麟 9000c 硬件加速兼容层，支持 Maleoon 910 GPU 硬件加速
- 硬件查看器新增驱动安装功能，支持用户在硬件查看器中自动方便的安装驱动包
  ![硬件查看器新增驱动安装功能](/news/25.5b1/gxde-hardware-viewer-driver-install.jpg)



## 大量故障修复

- **Wayland 环境**：修复双标题栏、输入法候选框错位、快捷键失效、锁屏后分辨率丢失等问题
- **桌面组件**：修复任务栏托盘爆炸、启动器触屏无效/响应慢、控制中心启动慢/位置异常/键盘设置崩溃、文件管理器壁纸设置失败等问题
- **系统层面**：修复 Wayland/X11 切换导致 Dock 失效、D-Bus 冷启动崩溃等问题
- **众多应用修复**：涉及终端、编辑器、视频播放器、录音机、字典、硬件查看器、投屏、截图录屏、天气等

## 详细更新日志

### ✨ 新增功能与组件

#### 一、Wayland 会话与合成器

##### `gxde-wayland-session`
- 提供 GXDE 的 Wayland 会话集成元包，串联 Wlcom、Dock、文件管理器、桌面面板等组件
- 支持自动安装 `gxde-wlcom` 会话与 `startgxde_wlcom` 启动脚本至系统
- 一键安装 Wayland 会话所需全部组件，包含 `gxde-desktop-panel-neo`、`gxde-dock`、`gxde-file-manager` 等
- 依赖 `dtk2widget-qt6`、`gxde-daemon`、`deepin-daemon` 等，确保模块版本匹配

##### `gxde-wlcom`
**新增协议与功能**：
- **会话锁屏**：新增 `ext_session_lock_manager_v1` 协议支持，实现原生 Wayland 锁屏
- **截屏管理**：新增 `treeland-capture-unstable-v1` 协议，提供区域截屏、窗口截屏等交互
- **快捷键管理**：新增 GXDE 快捷键协议，通过 D-Bus 暴露 `ListAllActions`、`GrabNextKey` 等接口，使控制中心可在 Wayland 下录制快捷键
- **DTK5/DTK6 窗口模糊**：新增对 DTK5/DTK6 应用窗口模糊效果支持，通过 `org.kde.kwin.effect` 风格配置
- **OSD 弹窗**：NumLock / CapsLock / 音量按键触发时弹出 OSD 提示，提供视觉反馈
- **麒麟 9000c 硬件加速会话跳转**：检测到 `gxde-hisi-9000c-gpu-compat` 时自动跳转硬件加速启动器，未安装则回退软件渲染
- **强制 CSD 窗口圆角裁剪**：允许强制裁剪所有 CSD 窗口使其拥有圆角（实验性，默认未开启）
- **GTK 标题栏按钮控制**：新增 D-Bus 接口控制最小化/最大化/关闭按钮可见性，适配 GXDE 窗口管理风格
- **GTK 主题设置**：允许通过 D-Bus 接口设置 GTK 主题，与 XSettings 同步
- **XWayland 全局菜单导出**：支持 KDE AppMenu 协议兼容，使 GTK 应用菜单可在 GXDE 顶栏显示
- **Deepin 风格多任务视图**：允许通过原 Deepin WM 的 D-Bus 接口唤起 `Super + A` 快捷键的多任务视图（DKwin 风格）
- **循环激活窗口**：新增 D-Bus 支持 `ActivateNextWindow` 方法，实现 `Alt+Tab` 循环切换同一应用的多个窗口
- **Qt 图标主题同步**：新增 Qt 图标主题同步机制，确保 Qt 应用图标与系统主题一致
- **Treeland Personalization Manager**：新增 `treeland-personalization-manager-v1` 支持，实现壁纸、光标等个性化设置同步
- **文本输入与截图协议**：新增 `ext-foreign-toplevel-list-v1`（外部位面列表）、`ext-image-capture-source-v1`（图像捕获源）、`ext-image-copy-capture-v1`（图像复制捕获）、`ext-screencopy-v1`（屏幕拷贝）等协议
- **XSettings IME 偏好**：合成器持有 XSettings，提供输入法（IME）偏好设置，如输入法切换、候选框位置等
- **剪切板持久化**：修正 wl_seat 广播时序，确保剪贴板内容在应用切换后仍然有效
- **PipeWire 支持**：支持 OBS 等应用通过 PipeWire 共享屏幕，实现屏幕录制和直播
- **性能优化**：禁用 `WLR_DRM_NO_ATOMIC` 提升性能，减少帧延迟
- **发行版支持**：新增 Arch Linux 构建支持，包括 x86_64 和 aarch64 架构的 PKGBUILD
- **多任务动画**：新增窗口缩放、魔术灯（Magic Lamp）等窗口切换动画效果
- **窗口切换器**：实现类似 KWin 的窗口切换器（Alt+Tab），支持缩略图预览
- **显示桌面（Toggle Desktop）**：提供显示桌面功能，快捷键 `Super + D`
- **顶栏信息查询**：新增 D-Bus 接口获取当前活动窗口标题、应用图标等，供顶栏显示
- **XWayland 菜单导出**：支持 XWayland 应用导出菜单，使旧应用也能在 Wayland 下使用全局菜单

**修复**：

- 新增 Wayland 文件选择器（file chooser）portal 支持，实现文件保存/打开对话框的 portal 后端
- 修复在 Wayland 下打开屏幕共享授权窗口时的段错误（修正 D-Bus 回调）
- 修复文件选择器无法选择文件夹的问题（修正模式参数）
- 修复 Treeland 个性化管理器协议操作码不匹配（更新协议版本）
- 屏幕选择器界面优化，并预设选中第一个屏幕

##### `gxde-requ`

- 修复热区定位异常，未触发左上角前无法触发另外三角热区的问题（修正坐标计算）

#### 二、GXDM

- **新增 DDE 15 风格的登录 UI 以及锁屏 UI**，基于 Qt Quick 实现，支持动效和自定义壁纸
- **新增 UI 动效**：登录选择、切换用户、锁屏等均有平滑动画
- **允许用户修改 Greeter 壁纸与光标（全局）**：通过 D-Bus 接口 `SetWallpaper`、`SetCursorTheme` 实现
- **允许用户在 Wayland 与 X11 greeter 之间切换**（默认 Wayland 且偏好 GXWM），提供会话选择器
- **允许用户修改自己的锁屏壁纸**：在控制中心或文件管理器设置壁纸时同步更新锁屏壁纸
- **锁屏注册开关**：用户可自行开关锁屏注册，在 `Super + L` 组合键可用且用户允许时自动注册
- **构建系统**：从 QMake 切换至 CMake，并新增 Bazel 支持（DEB 打包默认使用 CMake），简化跨平台构建
- **自动登录功能**：支持通过配置文件或 D-Bus 设置自动登录用户
- **会话记忆**：记住上次登录使用的会话类型，下次自动选中
- **虚拟键盘支持**：在登录界面显示虚拟键盘，适用于触屏设备
- **双屏 DPI 修复**：多显示器下 DPI 设置正确
- **修复锁屏第二次无法锁定的问题**（修正锁屏状态机）
- **依赖关系**：打破对旧版 `gxde-wlcom` 的兼容，要求 `>= 2.1.9-gxde1`
- **壁纸持久化**：用户自定义锁屏壁纸存储在 `~gxdm` 目录，登录界面可读取



#### 三、系统管理组件

##### `gxde-k9`
- 新增任务生命周期管理（start/stop/restart/disable），用于管理用户级服务
- 新增 `chocker` TUI 管理工具（基于 whiptail/dialog），提供交互式任务管理菜单
- 新增任务日志查看与自动补全（bash 补全脚本）
- 系统任务启停不再强制要求 sudo，仅 enable/disable 需要权限
- GXDE Daemon 切换到 GXDE K9 管理多个子 Daemon，如 Dock、顶栏等
- 支持导入外部脚本作为任务（如 `.slimy`、`.shot` 类型）
- TUI 菜单支持返回上一级、滚动查看日志、批量移除任务
- 新增 `gxde-k9-chocker` 子命令，支持脚本友好的操作（status、restart、logs 等）
- 任务日志按任务分类存储，大小限制和启动清理

##### `gxde-daemon`
- **切换到 GXDE K9**：实现管理器 `gxde-daemon-manager` 用于管理多个子 Daemon，通过 `gxde-k9` 统一启动

- **新增主题加载 util**：用于向 Wayland 会话加载 GTK 主题，通过 D-Bus 通知 Wlcom
- **修复快速调用 SetTopPanel 等函数时启动多个应用实例**（修正单例检查）
- **修复 X11 下 Dock 智能隐藏失效**（修正窗口边缘触发逻辑）
- **修复 Dock 多窗口循环切换**（优化窗口激活算法）
- **移除无用 Wayland session**（清理历史遗留文件）
- **完善 Dock 右键菜单顺序与 i18n**：菜单项（打开、启动、取消固定、固定、所有窗口、强制退出、关闭所有）支持多语言翻译（zh_CN、ru_RU、es_ES、fr_FR、de_DE、ja_JP、ko_KR、pt_BR）
- **窗口识别优化**：优先匹配非隐藏的官方 desktop 文件，解决启动器图标与运行窗口合并错误
- **新增 CapsLock/NumLock 提示脚本**：按锁定键时弹出 OSD 提示
- **小小电脑 VNC 远程支持禁用 XShm**，修复无法正确启用 VNC 的问题

##### `deepin-liferaft`
- 系统内存/资源监控与生命周期管理组件，内置“内存救生圈”工具
- 监控系统内存压力，当内存不足时自动触发冻结/强制退出高内存应用
- 支持用户手动强制退出卡死应用，提供图形界面
- 通过 systemd 用户服务或 gxde-k9 启动，支持日志记录和国际化（中文、日语、韩语）
- 使用 DtkCore 日志系统，支持 journald 和文件输出
- 默认启用 systemd 服务

##### `deepin-daemon`
- 修复笔记本播放/暂停键只能暂停不能播放的问题（修正按键映射）
- 修复 X11 下显示桌面失效（`deepin-toggle-desktop` 在 X11 下无法使用的问题）
- 修复 Wayland 下 `deepin-toggle-desktop` 无法使用（改用 D-Bus 调用 Wlcom）
- 修复无法使用快捷键打开通知中心（补全 D-Bus 接口）
- 支持使用 prime-run 调用 Nvidia 显卡运行应用（新增环境变量检测）
- Wayland 下禁用不兼容模块（如部分输入设备模块），避免崩溃
- 修复 Wayland 状态在切回 X11 后未清除，导致 Dock 失效的问题
- 支持用户登出后重置 daemon，清理残留进程

##### `gxde-default-settings`
- NTFS 默认驱动由 ntfs3 调整为 NTFS plus（旧版驱动），提升 NTFS 文件系统兼容性和性能

- 默认开启 zram（压缩内存交换），提升系统响应速度

- 保留 sudo 启动图形应用所需的 Wayland 会话环境变量（XDG_SESSION_TYPE、XDG_RUNTIME_DIR、WAYLAND_DISPLAY、QT_QPA_PLATFORM），修复普通 sudo 启动图形应用段错误

##### `gxde-desktop-schemas`
- 新增 Electron 应用的屏幕缩放功能支持
- 支持使用 prime-run 调用 Nvidia 显卡运行应用（新增 gsettings 键）
