# GXDE 硬件查看器

## 概述

GXDE 硬件管理器是一款专为 GXDE 桌面环境设计的轻量级硬件信息查看器。它提供全面的系统信息监控，界面简洁直观。✨

## 功能特性 🚀

系统信息 🖥️: 操作系统详情、内核版本、架构、启动时间
CPU 监控 🔢: 实时 CPU 频率、核心信息和驱动详情
内存跟踪 🧠: RAM 和交换分区使用情况，包含详细统计
存储分析 💾: 磁盘分区、存储设备和 I/O 统计
网络概览 🌐: 接口信息、设备驱动和流量监控
显示信息 🖼️: 显卡详情、分辨率、色深和刷新率
音频设备 🔊: 输入/输出音频设备和驱动信息
输入设备 ⌨️🖱️: 键盘、鼠标和其他输入设备检测
驱动更新 ⬆️： 支持在系统源中获取驱动&内核的更新
多语言支持 🌍: 英文和中文界面
数据导出 📤: 将所有硬件信息导出为 JSON 格式到桌面
自定义背景 🖼️： 可以选择你喜爱的图片当作背景
支持触摸屏 🖥️
