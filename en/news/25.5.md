# GXDE 25.5 Changelog (2026.10.07)

![GXDE 25.5 X11](/news/25.5/desktop-x11.jpg)

GXDE 25.5 is the official release with the largest single update in GXDE history, including comprehensive Wayland support, Qt6 migration, kernel updates, driver upgrades, security vulnerability fixes, and bug fixes. This update involves more than 60 code repositories, with hundreds of new features, patches, performance optimisations, and security hardening measures.

## Wayland Support Essentially Ready

The GXDE desktop environment can now run fully in a Wayland session, and the main components have all been natively adapted:

- The compositor `gxde-wlcom` has been significantly upgraded, supporting session lock screen, screenshot management, global shortcuts, window blur/rounded corners, etc.
- Core components such as the dock, top panel, launcher, control centre, file manager, and top panel all support Wayland.
- Tray icons, screenshot/recording, hot corners, screen casting, and other functions work normally under Wayland.
- Shortcut key and input method issues have largely been fixed.
- The login manager `GXDM` has been upgraded, supporting Wayland/X11 session switching and a new UI.

> Users can select the **GXDE Wlcom** session at the login screen.

## More Components Migrated to Qt6

More than 20 core components have completed Qt6 migration, including: dock, top panel, launcher, control centre, file manager, session management, text editor, video player, voice recorder, font manager, system assistant, printer, clipboard, etc. At the same time, multiple Qt6-version foundational libraries have been added (DFrameworkDBus, gxde-network-utils, disomaster, libdbusmenu, qt6mpris, etc.).

## Kernel and Driver Updates

- Kernel updated to **6.18.53** / **6.6.157**
- Introduced MGLRU performance optimisations from the 7.2 kernel, improving zram compression performance and EXT4/XFS IOPS
- Fixed multiple kernel security vulnerabilities: Januscape (CVE-2026-53359), SCTPhantom (CVE-2026-64564), OVSwrap (CVE-2026-64531), etc.
- Added support for **NVIDIA 470 Tesla / 580 / 595** series drivers
- Uses NTFS Plus by default, improving NTFS filesystem performance
- Supports enabling the open-source Panfrost GPU driver on Pangu M900
- Added a hardware acceleration compatibility layer for Kirin 9000c, supporting Maleoon 910 GPU hardware acceleration
- zram memory compression using the lz4 algorithm is enabled by default to optimise system performance
- The hardware viewer now includes a driver installation function, allowing users to automatically and conveniently install driver packages from the hardware viewer  
  ![Hardware viewer driver installation](/news/25.5/gxde-hardware-viewer-driver-install.jpg)

## Massive Bug Fixes

- **Wayland environment**: fixed double title bars, input method candidate box misalignment, shortcut key failures, resolution loss after lock screen, XWayland input method missing characters, etc.
- **Desktop components**: fixed dock tray explosion, launcher touchscreen ineffectiveness/slow response, control centre slow startup/position anomalies/keyboard settings crashes, file manager wallpaper setting failures, etc.
- **System level**: fixed Dock failure after Wayland/X11 switching, D-Bus cold-start crashes, etc.
- **Numerous application fixes**: involving terminal, editor, video player, voice recorder, dictionary, hardware viewer, screen casting, screenshot/recording, terminal, top panel, application installer, launcher, etc.
