# GXDE DLNA Caster

## Overview

GXDE DLNA Caster is a utility that casts your desktop screen and audio to DLNA‑compatible TVs. Built with Qt6 + DTK2, it streams your desktop screen, system audio, or local media files to TVs via the DLNA/UPnP protocol, and also allows receivers to watch directly in their browsers without installing any client.

![GXDE DLNA Caster](/apps/gxde-dlna-caster/mainwindow.jpg)

## Main Features
- Automatically discovers DLNA playback devices on your local network
- Real‑time casting of desktop screen and system audio
- Cast local videos, music, and pictures
- Browser‑based casting: recipients can open a web page and watch immediately (no receiver installation needed)
- SSDP scanning across multiple network interfaces with local preview
- Adjustable frame rate, bitrate, and maximum picture height
- Remembers the last used casting parameters
