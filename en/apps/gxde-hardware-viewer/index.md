# GXDE Hardware Viewer

## Overview 🔍

GXDE Hardware Manager is a lightweight hardware information viewer designed specifically for the GXDE desktop environment. It provides comprehensive system information monitoring with a clean and intuitive interface. ✨

![GXDE Hardware Viewer](/apps/gxde-hardware-viewer/mainwindow.jpg)

## Features 🚀

- 1. System Information 🖥️: OS details, kernel version, architecture, uptime
- 2. CPU Monitoring 🔢: Real‑time CPU frequency, core details, and driver information
- 3. Memory Tracking 🧠: RAM and swap usage with detailed statistics
- 4. Storage Analysis 💾: Disk partitions, storage devices, and I/O statistics
- 5. Network Overview 🌐: Interface details, device drivers, and traffic monitoring
- 6. Display Information 🖼️: Graphics card details, resolution, colour depth, and refresh rate
- 7. Audio Devices 🔊: Input/output audio devices and driver information
- 8. Input Devices ⌨️🖱️: Keyboard, mouse, and other input device detection
- 9. Driver Updates ⬆️: Supports fetching driver & kernel updates from system repositories
- 10. Multi‑language Support 🌍: English and Chinese interfaces
- 11. Data Export 📤: Export all hardware information as JSON to the desktop
- 12. Custom Background 🖼️: Choose your favourite image as the background
- 13. Touchscreen Support 🖥️

# User Guide 📖

The application features a sidebar navigation with the following sections:

- 1. System 🖥️: Basic system and hardware overview
- 2. CPU 🔢: Processor details and real‑time usage monitoring
- 3. Memory 🧠: RAM and swap statistics
- 4. Storage 💾: Disk partitions and storage device information
- 5. Network 🌐: Network interfaces and traffic data
- 6. Display 🖼️: Graphics card and display settings
- 7. Sound 🔊: Audio input/output devices
- 8. Input Devices ⌨️🖱️: Keyboard, mouse, and other input devices
- 9. Driver Updates ⬆️: Supports fetching driver & kernel updates from system repositories
- 10. Data Export 📤: Click the menu button (☰) in the upper‑right corner and select "Export all information to desktop" to save all hardware information as a comprehensive JSON file. 📄
- 11. Custom Background 🖼️: Click the menu button (☰) in the upper‑right corner and select "Set background wallpaper" to choose your favourite image as the background. If you no longer need it, you can select "Remove background wallpaper" to revert to the default interface.
