# GXDE FileTransfer

GXDE FileTransfer is a desktop file transfer tool based on DTK/Qt, designed for side‑by‑side browsing of local and remote files. It supports FTP, SFTP, WebDAV, and WebDAVS connections, and provides features such as saving connections, drag‑and‑drop transfers, and a transfer queue.

![GXDE FileTransfer](/apps/gxde-filetransfer/mainwindow.jpg)

## Features

- Dual‑panel file browsing for local and remote directories.
- Quick connection bar supporting FTP, SFTP, WebDAV, and WebDAVS.
- Manage saved connections via the DTK settings dialog.
- Support for upload, download, and recursive folder transfers.
- Drag‑and‑drop files between local and remote panels.
- Support for dragging remote files directly to GXDE File Manager via XDS direct save.
- Support for remote deletion, moving, and folder size calculation.
- Provides a transfer list and connection logs for tracking operation status.
